# Иконка приложения TempoCue

`AppIcon.ico` — единый значок приложения. Он используется для исполняемого файла,
окна WPF, панели задач Windows и переключателя Alt+Tab.

Чтобы заменить значок, достаточно сохранить новый многоразмерный ICO под именем
`AppIcon.ico` и пересобрать приложение. Рекомендуется включать размеры 16, 20, 24,
32, 40, 48, 64, 128 и 256 пикселей, чтобы Windows не масштабировала один вариант
для всех режимов отображения.

SVG-файлы из `../Icons/Source` относятся к иконкам интерфейса и не определяют
значок исполняемого файла.
