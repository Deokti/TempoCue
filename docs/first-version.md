# Первая техническая версия

Статус: завершена. Документ сохраняет первоначальную границу прототипа; текущее состояние продукта описано в корневом `README.md`.

## Цель

Проверить основную цепочку продукта без зависимости от League of Legends и компьютерного зрения:

```text
все участники матча → определение матчапа → Coach Pack → правило → совет → журнал
```

## Сценарии приёмки

1. При `Urgot vs Sett`, первом уровне и без предмета отображается состояние «Опасно».
2. На девятом уровне без Black Cleaver отображается состояние «Осторожно».
3. На девятом уровне с Black Cleaver отображается состояние «Можно играть».
4. Для отсутствующего матчапа приложение честно сообщает, что правило не найдено.
5. Некорректный Coach Pack не загружается.
6. В матче 5×5 активный игрок, союзники и противники разделяются по командам.
7. Для активного игрока на TOP определяется вражеский участник с позицией TOP.

## Сознательно отсутствует

- подключение к League of Legends;
- распознавание миникарты;
- голосовые сообщения;
- сохранение матчей в SQLite;
- OpenAI API;
- пользовательский редактор Coach Packs.

## Следующий этап

Этап выполнен: `TempoCue.Riot` получает Live Client Data, а сценарий активной сессии находится в `TempoCue.Application`. Ядро правил продолжает использовать те же независимые модели матча.
