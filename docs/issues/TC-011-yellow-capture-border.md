# TC-011. Жёлтая рамка захвата вокруг окна игры

- Статус: закрыта. Рамка снимается, вопрос о согласии выяснен замером
- Открыта: 2026-08-27
- Решено: 2026-08-27, коммит `8f97097`
- Область: захват окна
- Затронутая версия: 0.5.0

## Наблюдаемое поведение

Windows обводит захватываемое окно жёлтой рамкой. Она появляется с началом
захвата и держится всё время работы приложения. Игроку она мешает, а к нашему
коду отношения не имеет: рисует её система.

## Почему нельзя было просто убрать

Свойство `GraphicsCaptureSession.IsBorderRequired` существует, но записать в
него `false` без разрешения нельзя — вызов бросает исключение. Разрешение
запрашивается у системы через `GraphicsCaptureAccess.RequestAccessAsync` с
видом `Borderless`.

Оба API появились в Windows 11, а собирались мы против SDK 19041, где их нет
вовсе. Целевая версия SDK поднята до 22621, минимальная поддерживаемая система
оставлена прежней через `SupportedOSPlatformVersion`, вызовы закрыты проверкой
версии во время работы.

## Согласие: ожидание не совпало с замером

Ожидалось системное окно с вопросом, и был записан открытый вопрос — сработает
ли запрос для приложения **без пакетной идентичности**, каким TempoCue и
является.

Замер на живой Windows 11: **окна согласия не появляется, доступ выдаётся
сразу**. Рамка исчезает с первого запуска. Окно предназначено для приложений в
пакете; обычному приложению рабочего стола система разрешает молча.

Полагаться на это как на правило нельзя: политика домена или другая сборка
Windows могут ответить иначе. Поэтому отказ обрабатывается наравне с
разрешением, и приложение с рамкой работает точно так же.

## Что показывает диагностика

В карточке захвата строка «Жёлтая рамка захвата» с одним из ответов: снята,
осталась без разрешения, осталась из-за Windows 10, выясняем. Без неё исчезнувшую
и оставшуюся рамку не с чем связать — три разные причины выглядят на экране
одинаково.

Формулировка «снята с вашего разрешения» была исправлена на «снята» сразу после
замера: пользователя никто не спрашивал, и обещать ему участие в решении, которого
не было, нельзя.
