# ReplayInspect

Служебный инструмент разбора сохранённых кадров миникарты. В поставку приложения
не входит и нужен для того, чтобы решения по распознаванию принимались по
измерениям корпуса, а не по одному наблюдению на экране.

Запуск из каталога инструмента:

```powershell
dotnet run -c Release -- <режим и аргументы>
```

## Разбор одного кадра

```powershell
dotnet run -c Release -- ..\..\tests\TempoCue.Vision.Tests\ReplayCorpus\static-marker-as-sion-04.tempocue-vision
```

Показывает состав эталонов, число контуров и областей сравнения, все подтверждения
с их сходством и происхождением контура. Если рядом лежит файл разметки, дополнительно
сверяет результат с ней и перечисляет пропущенных чемпионов.

## Почему область не подтвердилась

```powershell
dotnet run -c Release -- --diag <кадр>
```

Печатает для каждой области сравнения баллы сильнейших эталонов, сходство с
отрицательными эталонами и измерение кольца значка. Отвечает на вопрос, проиграл
чемпион конкуренту, не дотянул до порога или был отклонён как статичный объект.

```powershell
dotnet run -c Release -- --probe <кадр> 154 248
```

То же самое для произвольной точки канонического кадра `320 × 320`, даже если
конвейер не создал там область. Нужен, когда чемпион виден глазами, но не попал
ни в одно предложение.

```powershell
dotnet run -c Release -- --solo <кадр>
```

Прогон с каждым эталоном по отдельности. Отделяет слабое сходство самого портрета
от проигрыша соседнему участнику.

## Измерения по всему корпусу

```powershell
dotnet run -c Release -- --calibrate ..\..\tests\TempoCue.Vision.Tests\ReplayCorpus
```

Базовый уровень каждого эталона: его баллы на своих и чужих областях. Показывает,
что сырые баллы разных эталонов несравнимы между собой.

```powershell
dotnet run -c Release -- --margin ..\..\tests\TempoCue.Vision.Tests\ReplayCorpus
```

Запас лучшего балла над отрицательными эталонами отдельно для настоящих портретов
и для областей без чемпиона. Обосновывает границу, начиная с которой область можно
считать уверенно портретом.

```powershell
dotnet run -c Release -- --stickiness <кадр>
```

Липкость эталонов друг о друга, измеренная офлайн из самих портретов без игровых
кадров. Статистику чужих баллов нельзя набрать по живым матчам: каждый чемпион
встречается в считаных играх.
