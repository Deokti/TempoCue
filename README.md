# TempoCue

Рабочее название локального AI-ассистента для League of Legends.

Текущая версия: **0.2.0 (alpha)**. Состав версии описан в [истории изменений](CHANGELOG.md).

Сейчас TempoCue подключается к локальному Riot Live Client Data API, показывает состояние активного матча и детерминированно выбирает matchup-совет из JSON Coach Pack.

## Что уже работает

- отдельное ядро правил без зависимости от интерфейса;
- загрузка и проверка Coach Pack из JSON;
- единая модель состояния пользователя, союзников и противников;
- разделение участников по командам и позициям;
- автоматическое определение противника на линии в составе 5×5;
- запрос полного JSON активного матча через Riot Live Client Data API;
- автоматическое обновление данных матча раз в секунду;
- отдельный экран текущего матча в стиле дизайн-системы TempoCue;
- составы обеих команд с позицией, уровнем, K/D/A и CS;
- события убийств чемпионов с известными убийцей и жертвой;
- события взятия драконов с их типом;
- тестовый матчап `Urgot vs Sett`;
- три состояния: ранняя линия, девятый уровень без предмета и power spike;
- советы по фактическому уровню и предметам активного игрока;
- карточная библиотека коучинга с поиском и разделами матчапов, контроля игры и пользовательских наборов;
- пятиэтапный редактор матчапа: метаданные, чемпионы и роль, фазы с постоянными подсказками и блоками предметов, симуляция результата и локальное сохранение;
- сохранение и повторная загрузка пользовательского Coach Pack схемы 2 с отдельным состоянием «черновик/включён/выключен» из `%LocalAppData%/TempoCue/CoachPacks`;
- загрузка списка патчей, локализованных каталогов и адресов изображений чемпионов и предметов из Riot Data Dragon с локальным кешем каталогов, фильтрацией предметов и просмотром их цены и известных характеристик;
- просмотр встроенных и пользовательских Coach Pack на отдельных вкладках «Обзор», «Советы» и «Предметы» без изменения исходных данных;
- экспорт выбранных непустых блоков предметов в совместимый League item set JSON с проверкой ID чемпиона и предметов по Data Dragon;
- русская и английская локализация интерфейса;
- автоматические тесты Core, Application, Riot и WPF-представления.

Советы в Coach Pack основаны на гайде GoliathGames, но перед игровым использованием их нужно проверить и привязать к актуальному патчу.

## Запуск

```powershell
dotnet restore
dotnet test
dotnet run --project src/TempoCue.App
```

## Структура

```text
src/TempoCue.App        WPF Views, ViewModels и composition root
src/TempoCue.Application сценарии приложения и порты внешних эффектов
src/TempoCue.Core       состояние, Coach Packs и движок правил
src/TempoCue.Riot       Live Client Data, Data Dragon, внешние DTO и преобразование JSON
tests/TempoCue.Core.Tests
tests/TempoCue.Application.Tests
tests/TempoCue.Riot.Tests
tests/TempoCue.App.Tests
docs/first-version.md    границы первой версии и следующий этап
```

## Разработка

Сообщения коммитов оформляются по [правилам Conventional Commits проекта](docs/commits.md): технические `type` и `scope` пишутся на английском, описание — на русском.

Обязательный порядок реализации, запуска новой сборки и визуальной сверки WPF-интерфейса описан в [рабочем процессе разработки](docs/development-workflow.md).

При каждом push и pull request GitHub Actions автоматически восстанавливает зависимости, собирает решение в конфигурации Release и запускает все тесты на Windows.

## Язык проекта

Описания и тела сообщений коммитов, описания merge request и написанные разработчиками комментарии в коде оформляются на русском языке. `type` и `scope` коммита, а также имена типов, методов и переменных остаются на английском.

## Следующий технический этап

Следующая итерация подключит включённые пользовательские наборы к активному движку и добавит редактирование уже сохранённого набора. Затем появится безопасный импорт Coach Pack; прямая установка item set в League Client останется отдельным интеграционным этапом после регистрации продукта. Анализ миникарты и компьютерное зрение идут отдельным последующим этапом.

Разделение библиотеки и план безопасного обмена пользовательскими Coach Packs описаны в [документе о коучинге](docs/coaching-library.md).
