# RiftCoach

Рабочее название локального AI-ассистента для League of Legends.

Сейчас реализована первая техническая версия: WPF-симулятор загружает JSON Coach Pack, принимает состояние матча и детерминированно выбирает matchup-совет.

## Что уже работает

- отдельное ядро правил без зависимости от интерфейса;
- загрузка и проверка Coach Pack из JSON;
- тестовый матчап `Urgot vs Sett`;
- три состояния: ранняя линия, девятый уровень без предмета и power spike;
- журнал симуляции;
- автоматические тесты ядра.

Советы в тестовом Coach Pack демонстрационные. Перед игровым использованием их нужно проверить и привязать к актуальному патчу.

## Запуск

```powershell
dotnet restore
dotnet test
dotnet run --project src/RiftCoach.App
```

## Структура

```text
src/RiftCoach.App        WPF-интерфейс и симулятор
src/RiftCoach.Core       состояние, Coach Packs и движок правил
tests/RiftCoach.Core.Tests
docs/first-version.md    границы первой версии и следующий этап
```

## Язык проекта

Сообщения коммитов, описания merge request и написанные разработчиками комментарии в коде оформляются на русском языке. Имена типов, методов и переменных остаются на английском в соответствии с соглашениями C#.
